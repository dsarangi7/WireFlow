# Request to evaluate an internal Visio integration

Hi Teresa,

We are developing AYK WireFlow to help engineers prepare and review battery-rack
wiring diagrams in Visio. The current proposal is a Windows desktop COM add-in
for Visio Professional 2021, 64-bit. It would let an engineer select terminal
positions and create editable draft wiring shapes directly in an open drawing.
The engineer would review all connections, routes and harness choices.

The add-in is an early prototype; it has not been installed, approved, signed
or released. There is no add-in login link yet. The existing browser prototype
is https://dsarangi7.github.io/WireFlow/ and currently has no employee sign-in;
please do not use it for confidential production drawings until AYK approves
its hosting and access controls. The desktop prototype source and status are at
https://github.com/dsarangi7/WireFlow/tree/main/visio-addin and
https://github.com/dsarangi7/WireFlow/blob/main/docs/visio-desktop-prototype.md.

Could IT advise on:

1. Whether AYK permits an internally developed Visio COM add-in and what review
   is required before a pilot installation.
2. The preferred installer and deployment method, and whether per-user or
   machine-wide registration is permitted.
3. Code-signing, trusted publisher, endpoint protection and update requirements.
4. How to restrict access to AYK engineers, including whether Microsoft Entra
   ID and company-managed hosting or storage are required.
5. Whether engineering drawing data may stay on the engineer's computer or
   needs an approved company-managed location and audit process.

Thank you!
